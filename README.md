# apps-privacy

Políticas de privacidade dos meus apps, publicadas pelo GitHub Pages.

Cada app tem a própria pasta com um `index.html`:

| app | link |
|---|---|
| Brick Breaker (`br.quebrablocos`) | https://yanalexander.github.io/apps-privacy/brick-breaker/ |

**Nunca renomeie nem apague a pasta de um app publicado**: o link está cadastrado no Play Console.

Para um app novo: crie `nome-do-app/index.html` e adicione o link no `index.html` da raiz e nesta tabela.
